Offensive Security Consultant at Klogix

Dec 2025 career

This past semester I had the amazing opportunity to work with Klogix's Offensive Security Testing Team as a Consultant/Pentesting Co-op! My job was to find vulnerabilities in client applications and report back to them to give them mitigation strategies or suggest ways to improve their security posture.

The majority of my tests were for Web Applications & APIs but I also got to try my hand at infrastructure testing for various internal networks and active directory environments.

Here are some of the fun things I learned

  • Almost every web application vulnerability came from authorization workflows whether that be no middleware checks or misuses of json web tokens. These also usually came from updating infrastructure and missing edge cases.
  • Internal Network Pen Tests are super hard and I felt the most out of depth here because I did not learn this stuff in class but using Bloodhound and automated pathfinding was possibly the coolest tool I have used.
  • I got to see how privilege escalation and lateral movement works across a network via cool attack chains such as Multicast Network Poisoning for initial access to Kerberoasting for escalation to forging a Golden Ticket to maintain Domain Admin.
  • Enable SMB signing
  • Don't use the Responder tool in Analyze mode unless you want to set off a bunch of security alerts to your clients.

My takeaway at the end of this is that I think this is the best first co-op I could have asked for! The people on this team are so incredibly talented and smart. If I ever felt overwhelmed or lost, everyone took the time to make sure I understood what was going on. It was a pleasure to get to learn from them and I hope to see them again in the future :)
